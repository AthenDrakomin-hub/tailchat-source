# Web 试运营首周日报模板

## 使用说明

这份模板用于 Web 端试运营首周的每日汇报。

建议每天固定在同一时间输出一版，推荐包含：

- 当日总体状态
- 主链路表现
- 新增问题
- 已处理问题
- 是否继续放量
- 次日动作

建议命名方式：

- `Day 1`
- `Day 2`
- `Day 3`

也可以复制本模板后按日期单独保存。

## 附：日报快速判定规则

### 判定为“正常”

满足以下条件：

- 无 P0 问题
- 登录、群组、私信主链路可用
- 用户反馈主要集中在 P1/P2
- 状态中心无基础服务异常

### 判定为“可继续观察”

满足以下任一条件：

- 有局部问题，但不阻断主链路
- 某条链路偶发异常，但可恢复
- 用户问题数量上升，但仍可控

### 判定为“需要收敛”

满足以下任一条件：

- 多个 P1 同时出现
- 同一链路被反复反馈
- 用户完成主链路比例明显下降

### 判定为“建议暂停放量”

满足以下任一条件：

- 出现 P0
- 登录、群组、私信任一主链路阻断
- 状态中心出现基础服务异常
- 当天值守无法及时响应
