# 財訊 IM 第五阶段群大厅联动设计

## 1. 目标

在第四阶段已形成“群公告可读、群大厅会话可读、群最近消息可读、动态详情可见关联群摘要”的基础上，第五阶段继续强化：

**看内容 -> 看群最近氛围 -> 进入群 / 直接向群大厅发言**

本阶段让“群大厅”从隐性存在，变成内容承接链路中的显式核心节点。

## 2. 范围

### 2.1 账号控制层

在 `openapi.account` 上增加：

- `sendGroupLobbyMessage`

该动作接受：

- `groupId`
- `content`

服务端内部自动解析群大厅会话，并向该群大厅发送消息。

### 2.2 动态详情页增强

在动态详情的关联群摘要卡片中继续补充：

- 群最近消息预览
- 更清晰的“当前群在聊什么”感知

这样用户不必先进入群再判断氛围，而是在内容场就能看到群当前状态。

## 3. 设计原则

- 继续复用 `group.getGroupLobbyConverseId`
- 继续复用现有 `chat.message.fetchConverseMessage` / `chat.message.sendMessage`
- 不新增复杂群页面，只增强内容详情中的群承接卡片

## 4. 不在本轮处理

- 群消息搜索
- 群大厅富文本摘要
- 动态到群的一键加入
- 群自动欢迎 / 自动回复策略

## 5. 预期结果

完成后，`財訊 IM` 将进一步具备：

- 内容场能看到群最近交流氛围
- 账号可直接围绕群大厅发起动作
- “内容场 -> 群大厅”成为更顺滑的单条运营链路
