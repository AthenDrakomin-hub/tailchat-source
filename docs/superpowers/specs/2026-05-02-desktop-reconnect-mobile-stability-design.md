# Desktop 工作区重连与 Mobile 稳定状态设计

## 1. 目标

继续沿客户端优先路线推进，把桌面端当前工作区的恢复动作和移动端恢复后的稳定状态再推进一步。

## 2. 范围

### 2.1 Desktop 当前工作区重连

- 在 `client/desktop` 主窗菜单中增加显式的“重新连接当前工作区”动作
- 复用当前工作区 URL 与已有加载反馈链路

### 2.2 Mobile 稳定状态表达

- 在 `client/mobile` 恢复成功提示结束后，继续保留稳定连接状态
- 让移动端不只展示瞬时恢复成功，还能展示持续稳定状态

## 3. 设计原则

- 不改现有主架构
- 不新增复杂原生基础设施
- 保持低风险增量修改

## 4. 预期结果

- Desktop 当前工作区可直接重连
- Mobile 恢复后的稳定状态可持续感知
