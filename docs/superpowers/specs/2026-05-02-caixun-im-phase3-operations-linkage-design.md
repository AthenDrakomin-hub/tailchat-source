# 財訊 IM 第三阶段运营链路强化设计

## 1. 目标

在第二阶段已形成“动态详情 / 评论 / 个人动态页 / 群导流 / 账号控制主链路接口”的基础上，第三阶段继续围绕运营闭环强化：

**内容发布 -> 内容互动 -> 群承接 -> 账号读取上下文 -> 账号继续动作**

这一阶段不做大规模视觉重构，而是把产品从“可用”推到“更适合被运营和自动化驱动”。

## 2. 重点范围

### 2.1 动态内容场增强

- 动态页增加更清晰的视图切换：
  - 全部动态
  - 我的动态
- 动态详情页中的互动状态更完整：
  - 评论数量
  - 点赞数量
  - 评论新增后即时反馈

### 2.2 群承接增强

- 群头部直接展示更清楚的群说明 / 公告信息
- 用户进入群时，不必再先点详情才能理解群当前状态
- 群组作为内容承接场的产品表达更完整

### 2.3 账号控制层增强

在 `openapi.account` 上补足模型运营最需要的“读取上下文 + 执行动作”能力：

- `listFeedComments`
- `likeFeedPost`
- `listGroupMembers`
- `getConversationDetail`
- `listConversationMessages`

## 3. 设计原则

- 继续沿用现有 Tailchat 结构增量扩展
- 优先让“运营链路”顺，而不是追求一次性接口铺满
- 所有接口保持账号控制语义，不引入 bot / robot 术语
- 前台继续维持“熟悉型 IM + 财富论坛内容场”的主气质

## 4. 不在本轮处理

- 推荐流
- 富媒体编辑器升级
- 动态审核系统
- 自动化剧本编排器
- 全量联系人自动化控制
- 大规模桌面端重构

## 5. 预期结果

完成后，`財訊 IM` 会进一步具备以下特征：

- 动态内容场对用户更顺手
- 群组承接更直观
- 外部模型可以读取更多上下文并执行更连续的动作
- 平台更接近“可被自动化长期运营”的状态
