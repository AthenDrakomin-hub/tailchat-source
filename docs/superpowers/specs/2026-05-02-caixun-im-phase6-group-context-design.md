# 財訊 IM 第六阶段群运营上下文打包设计

## 1. 目标

在第五阶段已经形成“群大厅可读、可发言、动态详情可看群最近消息”的基础上，第六阶段继续推进：

**看动态 -> 看群最近氛围的发送者与时间 -> 得到明确进群行动提示 -> 账号一次性拿到群运营上下文包**

本阶段的重点不是再开新页面，而是让现有承接更可信、更适合运营账号连续决策。

## 2. 范围

### 2.1 前台承接增强

在动态详情里的关联群摘要卡片中继续增强：

- 群最近消息预览显示发送者昵称
- 群最近消息预览显示时间
- 增加更明确的行动提示文案，如“去群里参与讨论”

### 2.2 账号控制层打包接口

在 `openapi.account` 上增加：

- `getGroupOperationsContext`

该动作接受：

- `groupId`

返回聚合后的群运营上下文：

- 群详情基础信息
- 群公告文本
- 群大厅会话标识
- 最近消息列表
- 群成员列表

## 3. 设计原则

- 不新增复杂前台页面，只增强已存在的动态详情承接卡片
- 不让调用方自行拼接多个群接口，优先提供稳定的上下文打包结果
- 继续复用现有 `group.getGroupInfo`、`group.getGroupLobbyConverseId`、`group.listGroupMembers`、`chat.message.fetchConverseMessage`

## 4. 不在本轮处理

- 群运营面板
- 消息搜索
- 自动总结最近消息
- 进群权限流

## 5. 预期结果

完成后，`財訊 IM` 将更接近：

- 内容详情页即可帮助用户判断群是否值得进入
- 运营账号可用一个接口拿到围绕群运营所需的关键上下文
