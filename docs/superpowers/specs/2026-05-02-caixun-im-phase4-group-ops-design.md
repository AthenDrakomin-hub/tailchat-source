# 財訊 IM 第四阶段群运营上下文强化设计

## 1. 目标

在第三阶段已经补齐“会话详情、会话消息、群成员、动态评论等上下文读取动作”后，第四阶段继续围绕群运营场增强：

**群公告可读 -> 群最近消息可读 -> 动态详情可见群摘要 -> 账号可围绕群做连续运营**

这一阶段强调“群运营上下文”和“群关联内容承接”，而不是继续铺一大批无序接口。

## 2. 范围

### 2.1 群运营接口显式化

在 `openapi.account` 上增加更直接的群运营读取动作：

- `getGroupAnnouncement`
- `getGroupLobbyConversation`
- `listGroupRecentMessages`

其中：

- `getGroupAnnouncement` 返回群说明 / 群公告文本
- `getGroupLobbyConversation` 返回群大厅会话标识
- `listGroupRecentMessages` 返回群大厅最近消息

### 2.2 动态详情中的群摘要承接

在动态详情页里，如果该动态关联某个群组，则展示一个更清楚的群摘要卡片：

- 群名称
- 成员数量
- 群说明 / 公告摘要
- 进入群组按钮

这样内容场不会只停留在“跳转链接”，而是会先展示群的基本状态，帮助用户决定是否进入。

## 3. 设计原则

- 继续沿用现有 Tailchat 结构和已有 `group.getGroupBasicInfo` / `group.getGroupLobbyConverseId`
- `openapi.account` 只暴露明确、稳定、面向账号控制语义的动作
- 前台承接先追求清楚和可信，不追求复杂运营面板

## 4. 不在本轮处理

- 群消息搜索
- 群公告历史版本
- 群多公告系统
- 动态推荐排序
- 会话摘要自动生成

## 5. 预期结果

完成后，`財訊 IM` 将进一步具备：

- 账号可显式读取群公告和群最近上下文
- 动态详情对关联群的承接更完整
- 群运营链路比当前版本更接近可持续日常使用
