# Desktop 主窗加载反馈与输入区稳定感设计

## 1. 目标

继续沿客户端优先路线推进，把桌面端和 Web 聊天区的连续使用感再收紧一层。

本轮聚焦：

- `desktop` 主窗口加载工作区时的状态反馈
- `web` 聊天输入区的稳定感与操作提示

## 2. 范围

### 2.1 Desktop 主窗加载反馈

增强 `client/desktop` 主进程中主窗口加载远程工作区时的反馈：

- 在开始加载时设置明确窗口标题
- 在加载进行中设置进度反馈
- 在加载完成或失败时更新窗口状态

目标是让桌面端进入主窗口后，不再像“黑盒打开网页”，而更像正在连接工作区的桌面客户端。

### 2.2 Web 聊天输入区稳定感

增强 `client/web` 的聊天输入区：

- 在输入区下方补充更明确的发送与素材操作提示
- 让私信和长期沟通的底部操作区更像成熟 IM 的输入区

## 3. 设计原则

- 不引入复杂桌面原生面板
- 不改 Web 聊天输入核心逻辑
- 优先提升用户对“当前是否正在工作”的感知
- 保持低风险增量修改

## 4. 不在本轮处理

- Desktop 主窗内嵌原生顶部工具栏
- Web 输入区功能扩展
- 桌面端更新弹窗
- 多工作区切换面板

## 5. 预期结果

完成后：

- Desktop 主窗加载工作区时的状态更可感知
- Web 输入区更像长期使用中的聊天工具底部区域
