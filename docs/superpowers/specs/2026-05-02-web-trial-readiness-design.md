# Web 试运营完善设计

## 1. 目标

把 `web` 端从“已经可用”继续推进到“更适合作为试运营主入口”的阶段。

## 2. 范围

### 2.1 试运营状态中心

增强 `client/web` 设置中的状态页：

- 不只展示技术服务列表
- 增加整体健康度总结
- 增加面向试运营用户的帮助与下一步建议

### 2.2 主链路起步承接

增强 `client/web` 个人区联系人页：

- 增加试运营起步建议
- 明确把用户引导到动态、群组、私信三条主链路

### 2.3 试运营帮助入口

增强 `client/web` 关于页：

- 增加试运营期的帮助与状态查看指引
- 补充信任与支持入口

## 3. 设计原则

- 不改核心架构
- 不新增复杂后端能力
- 优先补齐真实试运营时最常被问到的“现在能做什么、去哪看状态、出了问题怎么办”

## 4. 预期结果

- Web 设置页更像试运营状态中心
- Web 主区更像试运营用户的起步面板
- Web 关于页更像试运营支持入口
