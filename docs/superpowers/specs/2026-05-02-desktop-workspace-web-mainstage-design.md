# Desktop 当前工作区与 Web 聊天主场设计

## 1. 目标

继续沿客户端优先路线推进，把桌面端当前工作区表达和 Web 聊天主场的一致性再收紧一层。

本轮聚焦：

- `desktop` 当前工作区在主窗中的可感知与可操作性
- `web` 私信聊天主场的统一表达

## 2. 范围

### 2.1 Desktop 当前工作区

增强 `client/desktop`：

- 在主窗菜单中明确表达当前工作区对象
- 支持围绕当前工作区做更多直接操作

目标是让桌面端主窗更像客户端，而不是只打开了一个远程页。

### 2.2 Web 聊天主场

增强 `client/web` 私信聊天主场：

- 为消息区增加更统一的会话提示条
- 让头部、消息区、输入区的语义更一致

目标是让私信区更像一个统一的 IM 主场。

## 3. 设计原则

- 不改底层架构
- 不重做消息流
- 优先提升长期使用时的语义一致性
- 保持低风险增量实现

## 4. 不在本轮处理

- Desktop 多工作区常驻切换器
- Web 聊天布局重构
- Mobile 本轮新增主路径

## 5. 预期结果

完成后：

- Desktop 当前工作区会更像主窗中的正式对象
- Web 私信聊天主场会更统一、更像长期使用场景
