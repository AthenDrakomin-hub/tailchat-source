# 財訊 IM 第七阶段群运营摘要设计

## 1. 目标

在第六阶段已经形成“群运营上下文打包接口 + 动态详情中可见发送者和时间”的基础上，第七阶段继续推进：

**把群上下文从原始数据集合，推进成更适合运营决策的摘要包；同时让动态详情里的群卡片更容易帮助用户判断是否现在进入。**

## 2. 范围

### 2.1 群运营摘要接口

在 `openapi.account` 上增加：

- `getGroupOperationsSummary`

该动作接受：

- `groupId`

返回聚合摘要字段：

- 群基础信息
- 群公告
- 群大厅会话标识
- 成员数量
- 最近消息数量
- 最近活跃时间
- 最近消息列表

### 2.2 动态详情群卡片增强

在动态详情的关联群卡片中补充：

- 最近活跃时间
- 更明确的参与提示
- 当最近消息为空时的更清晰静态状态提示

## 3. 设计原则

- 继续复用已有 `getGroupOperationsContext`
- 摘要接口只做轻聚合，不做 AI 总结
- 前台继续只增强现有卡片，不引入新页面

## 4. 不在本轮处理

- 群自动摘要
- 群热度评分算法
- 群推荐排序
- 后台运营看板

## 5. 预期结果

完成后，`財訊 IM` 会更接近：

- 运营账号更容易基于一个简洁摘要判断是否要继续动作
- 用户在动态详情里更容易判断关联群当前是否活跃
