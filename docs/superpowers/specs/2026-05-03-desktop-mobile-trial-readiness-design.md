# Desktop 与 Mobile 试运营完善设计

## 1. 目标

把 `desktop` 与 `mobile` 从“已具备基础使用能力”继续推进到“更适合作为试运营辅助端和移动验证端”的阶段。

## 2. 范围

### 2.1 Desktop 试运营支持中心

增强 `client/desktop` 启动器：

- 增加试运营支持区
- 明确当前端定位与推荐体验路径
- 补充文档、信任、下载等帮助动作

### 2.2 Mobile 试运营入口指引

增强 `client/mobile` 入口页：

- 增加试运营起步建议
- 增加帮助与支持动作
- 让移动端从“能进入”升级成“知道如何进入试运营验证”

### 2.3 运营文档收口

补齐文档：

- Desktop 试运营上线清单
- Mobile 试运营上线清单

## 3. 设计原则

- 不重做 desktop / mobile 核心架构
- 优先补足试运营阶段最常用的帮助与支持信息
- 让两端更适合作为 Web 试运营的辅助端

## 4. 预期结果

- Desktop 具备更明确的试运营支持入口
- Mobile 具备更明确的试运营起步与支持入口
- 两端都具备各自可执行的试运营上线清单
